# Noxa Player for iPhone

Noxa Player is an unofficial, community-made iPhone client for the [Noxa media server](https://github.com/xenix13/Noxa). Browse your library, search for movies and shows, save favorites, or channel surf in Retro TV. The guide shows what is playing, and Start Over lets you watch the current program from the beginning.

[Download Noxa Player on the U.S. App Store](https://apps.apple.com/us/app/noxa-player/id6837519034).

## Run the app

Open `iPhone/NoxaPhone.xcodeproj` in Xcode, select the NoxaPhone scheme and an iPhone simulator, then press Run. Choose **Explore sample library** to try the bundled original shorts. To use your media, enter your Noxa server address and sign in with your viewer account. For a personal device build, select your own signing team and bundle identifier.

## Support

[Open a player issue](https://github.com/emerytech/noxa-player/issues) for iPhone playback, navigation, or Retro TV problems. Include the app version, iOS version, Noxa server version, and steps to reproduce. Keep passwords, invite links, and private server addresses out of public reports.
